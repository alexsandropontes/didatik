## 🧠 Learn

Abra conectando com a dor real do aluno: por que este conteúdo importa para ele?

- Explique o conceito em camadas (do simples ao complexo)
- Use uma analogia do dia a dia
- Traga exemplos progressivos
- Use tabelas e listas quando ajudar na clareza

## 🏃 Run

Exercício GUIADO, passo a passo. O aluno executa acompanhando.

**Passo 1 — Faça X**
Resultado esperado: ...

**Passo 2 — Agora faça Y**
Resultado esperado: ...

## 🚀 Fly

Desafio AUTÔNOMO. Sem passo a passo.

**Desafio:** [enunciado claro do que o aluno deve entregar/produzir]

**Critérios de sucesso:**
- [ ] ...
- [ ] ...
